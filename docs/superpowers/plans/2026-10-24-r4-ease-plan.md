# R4 易用/自愈 实施计划（v1.7.0）

路线图 docs/superpowers/specs/2026-10-23-wxbot-roadmap-design.md 第 7 节。

## 范围

1. **command.py 一句话操控**：自然语言 → 意图路由（LLM + 关键词快路径兜底）→ 白名单动作映射；双入口（文件传输助手对话台 + 群内管理员 @）；未识别明确说不支持（返回 None 走原问答，不误触）。
2. **watchdog.py 自愈守护**：微信进程守护拉起（可配）、连续读消息失败掉线告警（限频）、bot 崩溃自动重启（BotShell 定时拉起）、开机自启（HKCU Run 键，webui 一键）。只做恢复不做风控规避。
3. **零配置通道（本版不做服务端）**：需在 227 站公开 LLM 中继并消耗用户网关额度，属于共享基础设施/成本决策，待用户确认后单独实施；本版不埋任何密钥进仓库/安装包。

## command.py 设计

- 意图白名单（全部映射到既有函数，零新副作用路径）：
  `pause / resume`（全局暂停恢复）、`stop_active / resume_active`（gate 急停/恢复）、
  `missed`（digest.report_missed_now）、`status`（_do_admin 状态）、
  `reminders`（reminders.cmd_list）、`remind_add`（LLM 抽 {who,what,date,time} → 校验 60 天内 → add_reminder）、
  `recall`（recall.answer(query)）、`enable / disable {target}`（复用 _do_admin 开/关）。
- `route(bot, text)`：①关键词快路径（"暂停/恢复/补报/急停主动/恢复主动/状态/约定列表"等**整句级**确定性命中，防 LLM 慢/挂）；②LLM `personas.route_intent(text, base_date)` JSON；③解析失败/未知意图返回 None。
- `handle(bot, text) -> str|None`：route → execute；None=不是指令，调用方走原链路。
- 接线：`_on_console_msgs` 在 # 命令后、recall 前插 `command.handle`；`_group_qa` 在 `_maybe_task_command` 旁插同款（仅 `_is_task_admin`），命中即 send_quote 文本回复并 return。
- 安全：动作全为幂等/低风险；群入口有管理员门槛；对话台=主人；不过 gate（管理员发起，与 # 命令同级）。

## watchdog.py 设计

- `maybe_check(bot)`（主循环 60s 节流）：
  - `wechat_alive()`：tasklist 查 `Weixin.exe`/`WeChat.exe`；
  - 进程不在：`app.watchdog.restart_wechat`（默认 false）→ 按注册表 App Paths 拉起；`[守护]` 通知管理员，每类告警每小时最多 1 次（state 限频）；
  - `state["poll_fails"]` 连续 ≥5（run() poll 异常计数）→ 掉线告警（锁屏/微信退出提示），同样限频。
- BotShell 崩溃自愈：`_run` 异常退出时若 `app.watchdog.bot_restart`（默认 true）→ 30s 后 daemon Timer 自动 `restart()`。
- `set_startup(enable)`：HKCU `...\CurrentVersion\Run` 写/删 `wxbot`（frozen 用 sys.executable）；webui「守护」开关 POST /watchdog/autostart + 状态显示。
- 测试全部走注入 fake（tasklist 文本、注册表 dict、Timer 替身），不碰真机。
