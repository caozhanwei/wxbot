# 微信智能助手 PC 版（wxbot）

基于 [wechatauto-replica](vendor/wechatauto-replica)（本地库解密读消息 + UIA 写操作）的微信自动回复/群管理工具。适配微信 4.1.x（UIA 树需热激活，驱动会自动处理）。

> **免责声明**：本项目仅供个人学习研究 Windows UI 自动化与 RAG 应用技术。使用前请自行评估并遵守《微信个人帐号使用规范》等相关条款；因使用本工具产生的账号风控等一切后果由使用者自行承担。

## 快速开始

```
pip install -r requirements.txt
pip install -e vendor/wechatauto-replica   # 微信驱动库（Apache-2.0）
cp bot_config_template.yaml bot_config.yaml  # 填入你的 LLM/KB 网关地址与 key
python run_bot.py --check                # 自检：窗口/自身/LLM/KB 连通
python run_bot.py --list                 # 列出最近会话与群 id（用于填配置）
python run_bot.py --test-reply 文件传输助手 你好   # 全链路测试（请先用文件传输助手）
python run_bot.py                        # 启动（含 Web 状态页 http://127.0.0.1:8778）
python -m pytest tests/ -q               # 280+ 个用例
```

## 能力

- **私聊自动回复（白名单制）**：`bot_config.yaml` 的 `contacts` 里 `enabled: true` 的联系人才会 AI 回复；每个联系人可指定 `persona`（人设库自定义，语气/背景/表情习惯）
- **群答疑**：群内 `@机器人 + 问题` → 先结合群聊上下文**理解提问**（指代补全成独立问题再查库，"它多少钱"也能正中；闲聊/玩笑@不查库只轻接一句）→ 团队知识库（MCP `kb_ask`）RAG 回答；未正中但有引用来源 → 附参考回复并记入"待沉淀"（Web 页可见）；完全未命中 → 记录并私信管理员；知识库断线可按群回退人设 LLM **融入群讨论**作答（能引用群友昵称的观点，像顺着话头接话）
- **图片 OCR 理解**（v1.3.2）：群里的图片本地解密后经 OCR 服务识别成文字（如 `[图片:通知：明天停水]`）参与上下文理解与画像——问"这个通知说了啥"也能答；不配 `ocr` 段则图片仍是 `[图片]` 占位（语音识别暂缓，显示 `[语音]`）
- **引用消息读懂 + 原生气泡引用回复**（v1.4.0）：群里的 57 类型引用消息解析成 `[引用 某某: "原话"] 回复内容` 参与上下文；机器人答复时优先走 UIA 右键「引用」发出**微信原生引用气泡**（失败自动降级为「回复 @某某」前缀文本，绝不丢回复）
- **语音 ASR 多模态**（v1.4.0）：配置 `asr` 段（OpenAI 兼容 `/v1/audio/transcriptions` 或自建 HTTP ASR）后，语音本地解密为 SILK 直接送转写，上下文/画像/答疑全链路显示 `[语音:识别内容]`；不配置则保持 `[语音]` 占位，不影响其它功能
- **一键全量冷启动导入**（v1.4.0）：新群/首次使用时，Web 页群卡片点「🚀 全量冷启动」，后台扫描近千条历史消息三路并行——①活跃群友画像批量建立 ②共识 Q&A 问答沉淀 ③历史未解诉求/遗留问题识别（Web 页"待沉淀问题"卡片可见），彻底解决画像/知识库/待办的冷启动
- **私聊拟人化去 AI 味**（v1.4.0）：私聊回复自动**拆成 2~3 条短气泡连发**（拟真打字延迟，字符级拟合手速）；自动剥离开头"您好"、结尾"希望对您有所帮助"等 AI 口头禅与句尾句号；每位私聊联系人沉淀**长期生活记忆**（家人/车/项目/约定），下次对话自然融入，越聊越像老朋友
- **群聊闲聊机智接话**（v1.4.0）：被@开玩笑/调侃/纯互动时不再用"哈哈我在呢"死模板，改由人设引擎按群友画像生成幽默接地气的接话；知识库带参考回复时也先经人设润色成口语再发，不再往群里贴原始文档片段；同一会话 30 秒内完全相同的消息自动拦截，杜绝刷屏
- **群友画像**（v1.3.2，v1.3.3 增强）：按 群×成员 维护画像（身份线索/关注的事/语气态度/佐证事例，≤1000字，卡号证件等脱敏不记），答疑后后台自动更新（同一人 1 小时节流），回答时注入画像帮着洞察提问意图；Web 页"群友画像"卡片可**按群筛选、分页查看**、按群刷新；群问答库（挖掘）同样**按群筛选 + 分页**浏览
- **免@上下文回复**（v1.3.2）：群配置 `no_at_reply` 打开后，没人@机器人也会结合最近聊天判断——先把增量消息（脱敏后）提炼成问答对入知识库，再由 LLM 判定"值得接话"（有人提问/求资源/讨论可答话题）才回复（回复 prompt 并入知识库检索参考；纯闲聊不吭声）；同群冷却默认 3 分钟可配，@提问不受冷却限制
- **活跃分子模式**（v1.4.5）：群配置勾选 `active` 后，免@不再做"值不值得"智能判定，冷却一过就像真人群友一样自然接话（接梗/附议/补充/引申提问），当群里的活跃气氛担当；冷却仍节流，不会刷屏
- **群管理**：进群欢迎（模板）、违禁词监控 → 按人设生成劝告话术 → 达阈值私信管理员建议移出（**踢人需人工在微信操作**，避免误伤）
- **管理员命令**：私聊发 `#状态 #暂停 #恢复 #补报 #急停主动 #恢复主动 #开 <名> #关 <名> #重载 #待审 #帮助`
- **Web 状态页**（127.0.0.1:8778）：联系人/群开关、运行统计、日志、待沉淀问题、在线编辑配置（热重载；网页保存会丢注释，介意请直接编辑文件）
- **配置热重载**：`bot_config.yaml` 改完即生效（LLM 模型/温度/超时、联系人、人设、群、违禁词阈值等）
- **最近会话选择器**（v1.3.0）：Web 页"最近会话"卡片列出微信里点开过的聊天（支持关键字过滤），一键"加为联系人/加为群"，**无需知道任何 id**；手填昵称反查不到时自动给模糊候选；另有 `/api/sessions?q=关键字` JSON 接口
- **首启向导**（v1.3.0）：新装机第一次打开 Web 页引导三步——确认微信已登录 → 填模型接口/Key → 从最近会话挑对象；模板默认 `dry_run: true`（演示模式，只记日志不发送），验证后再关
- **多账号隔离**（v1.3.0）：登录后配置/数据库自动落到 `%APPDATA%\wxbot\<你的wxid>\`；换一个微信号登录自动切换（老账号数据原样保留，新账号从模板干净起步），给不同的人/号用互不串号
- **画像跨账号迁移**（v1.4.2）：Web 页"群友画像"卡片的「跨账号迁移」一键导出全部群友画像/私聊记忆/问答沉淀，换号登录后上传导入（可选覆盖已有），知识资产不随换号清零
- **手机历史消息利用**（v1.4.2）：手机微信「设置 → 通用 → 聊天记录迁移与备份 → 迁移」把聊天记录迁到电脑版微信后，群卡片「🚀 全量冷启动」的扫描条数可调至最多 10000 条，把手机上的历史也吃进画像/问答库
- **私聊记忆冷启动**（v1.4.4）：联系人卡片「🧠 提炼记忆」一键扫描私聊历史（含迁移来的手机记录），滑窗提炼该好友的长期记忆（家庭/喜好/约定），之后每次回复自动增量更新
- **本人画像 + 双向融合**（v1.4.4）：冷启动/画像刷新不再跳过你自己——你本人在群里的发言也会提炼画像，回复时同时注入**你的画像**（口吻立场一致）与**提问者画像**（洞察意图），交流更像你本人
- **定时增量画像**（v1.4.4）：`app.auto_profile_hours` 设为 >0（如 6）后，每 N 小时自动刷新启用群的活跃成员画像，新群友聊几句就有画像，无需手动
- **全量备份与一键恢复**（v1.4.6）：画像页「备份与迁移」导出 **ZIP 压缩包**（体积小；勾选**含配置**时包内附 bot_config.yaml 原文，含密钥注意保管）；导入同一压缩包可选**恢复配置**——换机/重装/换号一条龙，旧版导出的纯 JSON 也兼容；桌面窗口导出会弹保存对话框（v1.4.5 及之前桌面窗口点导出无反应，已修）
- **@机器人必回（v1.4.7）**：群成员用**群名片** @ 机器人（与微信昵称不一致）时不再漏答——直接读微信写入的 `atuserlist` 精确名单判定被@，配「剥 @ 前缀」兜底，群名片怎么改都不影响
- **群主/管理员定时任务（v1.4.7）**：群里 @机器人 说一句即可固化，如「@机器人 每天晚上9点总结一下群里的消息，让大家不错过重点」——到点自动把近 24h 群聊总结成要点播报；「看看定时任务」「取消第一个任务」管理；Web 控制台新增「群定时任务」卡片可视化删除
- **回复提速（v1.4.7）**：提问理解与知识库检索**并行**（省一跳网关往返）；轮询间隔默认 3s→1.5s；LLM 空回复重试预算翻倍，推理模型不再空转两轮
- **回复多样性（v1.4.7）**：近期发过的话注入 prompt 禁止换皮重复；生成结果与近期回复做二元组相似度检测，重复则带更强清单重生成一次，仍重复宁可沉默不刷屏——根治"笨笨机器人一直在说同一句话"
- **控制台卡片折叠**（v1.4.4）：每个卡片点标题即可收起/展开，状态记忆在本地，长页不再无限下翻
- **关于与一键升级**（v1.4.8）：Web 页「关于」卡片显示当前版本，一键检查 GitHub 最新 Release；有新版可直接下载安装包（带进度）→「立即安装并重启」，全程无需手动下载 MSI（配置/画像/聊天数据都在 %APPDATA%，升级不丢）
- **任务权限显性化**（v1.4.9）：「群定时任务」卡片直接显示谁有权限下任务指令——配置的管理员名单 + 每个群的群主（自动从微信读，无需去配置文件翻）
- **一键升级关键修复**（v1.4.10）：升级器启动标志由 DETACHED_PROCESS 改 CREATE_NO_WINDOW——前者会让 PowerShell 无控制台静默退出、脚本一行不执行（应用内点「立即安装」无任何反应的根因），已真机 1.4.9→1.4.10 升级链路验证
- **回复字数上限**（v1.4.11）：群卡片可设「回复字数上限」（0~200，0=不限）——嫌机器人话多就设小；生成端 prompt 与发送端双层兜底，超出自动按句边界截短（绝不腰斩半句话），@答疑与免@接话都生效
- **只答最新提问**（v1.4.11）：机器人忙不过来积压多条@时，一批里只回答**最新**的那条（旧@已被群聊顶替，补答只会答非所问）；超过 10 分钟的陈年@视为过气不再翻旧账（群可配 `qa.stale_min` 调整）
- **按群设置指令管理员**（v1.4.11）：群卡片「指令管理员」直接填**昵称**即可（无需知道 wxid，群名片带前后缀也能包含匹配），这些人 @机器人 就能下定时任务指令；全局管理员与群主天然有权限，「群定时任务」卡片会显示各群生效的管理员名单
- **镜像升级源默认固化**（v1.4.12）：无需任何配置，新装机检查更新即走国内镜像；上条能力自 v1.4.12 起内置默认
- **国内镜像升级源**（v1.4.11/1.4.12）：检查更新与下载默认走内置国内镜像（GitHub 直连不稳的环境开箱即用，**零配置**）；`app.update_mirror` 可覆盖为自己的镜像 URL；镜像不可用自动回落 GitHub Releases
- **引用回复不再回错人**（v1.4.13）：答疑要几十秒，期间别人插话后"引用最新一条"会引用到插话的人（A 提问、气泡却挂在 B 头上）——现在按**提问正文** OCR 定位到提问人那条再引用；定位不到就降级为「回复 @提问人」文本前缀，宁可不用气泡也绝不引错人
- **每晚群精华日报**（v1.5.0）：`app.daily_digest` 开启 + 群勾「进日报」后，每晚定时把各群近 24h 聊天交给 AI 出**热点话题摘要 + 值得一看的发言**，附**未解问题清单**与**找你的事**（@我未答 / 私聊找你），按群分条推送到指定会话（默认文件传输助手）；LLM 挂了自动降级"简版"（条数+高频词）照发不误；错过开机时刻当天补发、跨天不补
- **错过消息补报**（v1.5.0）：非白名单私聊**被动监听**（只记录绝不回复），群里 @我但没答上的（被新消息顶替/过气/全局暂停）全部入补报缓存；含"急/紧急/尽快/马上"等急件的私聊**即时推送**给你（深夜也推）；管理员随口一句 `#补报` 立刻汇总还没消化的事项
- **主动动作闸门**（v1.5.0）：日报/急件等一切机器人**主动发起**的发送统一过闸——时段窗（默认 8~22 点，急件豁免）、全局每小时上限、每会话每日上限，放行才计数发送并落审计日志；`#急停主动` 一键熔断全部主动动作（连急件也停），`#恢复主动` 解除
- **运营驾驶舱**（v1.5.0）：Web 控制台新增驾驶舱卡片——每群今日消息量/活跃人数/高频词/未解数/已沉淀数/日报状态一屏尽览，下方直接配日报开关与推送目标，主动动作审计（谁在几点推了什么）就地可查
- **文件传输助手=主人对话台**（v1.5.1）：在「文件传输助手」里发消息就是直接问助手——AI 抽关键词后**跨全部启用群+私聊**检索历史记录，整合成**带出处**（谁说的/哪个群/大概什么时候）的口语化回答；`#` 开头照走管理员命令；对话台不受暂停/闸门限制，机器人自己发的日报/回复不会被误当成提问；检索默认回溯 30 天
- **群精华主题库**（v1.5.1）：挖掘出的问答自动交给 AI **聚类成主题**（挖掘完成后自动跑，网页也可手动「整理主题」）；群答疑先撞本地主题库——该群沉淀过的同类问题**直接转述作答**（标注"群内沉淀"）不再查知识库，更快更贴本群实际；网页挖掘卡片新增**主题列+主题筛选**（`qa.local_first` 可按群关闭）
- **约定提醒**（v1.6.0）：私聊里双方说定的约定（谁/何事/何时）AI 自动抽取入库（每 30 分钟巡检增量，只认 60 天内防幻觉），到期自动推送——群里说的去群里 @相关人，私事推文件传输助手；`#提醒` 看待办、`#销项 <编号>` 完成；网页「约定提醒」卡片可直接销项
- **主动关怀**（v1.6.0）：`app.care` 开启后每天定时挑**超过 N 天没聊**的好友，结合长期记忆生成带记忆点的问候（不落"好久不见"俗套）；护栏全内置——默认演练（只记日志不真发）、每人每周最多 1 次、每日上限、8~22 点时段窗统一过闸门
- **未解问题闭环**（v1.6.0）：`#催办 <编号>` 自动到原群问"有小伙伴在跟进吗"，有答案后 `#已解 <编号> <答案>` 一句话归档——答案直接进该群主题库并自动聚类，下次同类问题本地秒答；`#待审` 看全量
- **群秩序自动化**（v1.6.0）：**刷屏检测**（1 分钟连发超 10 条告警管理员，每人每小时最多提示一次）、**退群预警**（主动退群/被移出群聊即时通知管理员）、**新人指路**（欢迎语自动附上该群沉淀的常见话题，新人不迷路）
- **一句话操控**（v1.7.0）：不用记 #命令——对话台/群管理员直接说人话「暂停一下」「补报」「周五上午十点提醒张三交材料」「帮我查查谁问过停水」「测试群太吵了先停用」；关键词快路径秒回 + LLM 意图路由兜底，**白名单动作映射**绝不越权执行，普通聊天零误触零额外延迟；群入口仅管理员可用
- **自愈守护**（v1.7.0）：**微信进程监测**（不在即告警管理员，可配自动按注册表路径拉起）、**掉线告警**（连续 5 次读消息失败提示检查微信/锁屏）、**崩溃自愈**（bot 异常退出 30 秒自动重启、启动失败 60 秒重试，`app.watchdog.bot_restart` 可关）、**开机自启**（网页「自愈守护」卡片一键开关 HKCU Run 项）；只做恢复不做风控规避
- **翻历史引用回复**（v1.7.1）：引用定位不再局限于可视区——答题几十秒、提问被插话顶出屏幕时，机器人**像人一样向上翻页**（滚轮+逐屏 OCR，最多 5 屏封顶）找到那句话再原生气泡引用，找不到滚回底部降级 `「回复 @某人」` 前缀，绝不引错人；**免@接话默认改用引用回复**点明在答谁（群配置 `no_at_quote: false` 可关）
- **自动更新修复与健壮化**（v1.7.2）：下载进度改为**网页实时轮询**（不再依赖整页自动刷新，"点了没反应"根治）；下载完成与安装按钮独立展示（无需再点检查更新）；下载线程卡死可自动重启下载；安装包下完自动 **sha256+大小校验**（镜像清单比对，损坏包绝不安装、自动清理重下）
- **广告号识别**（v1.7.2）：新成员进群 24h 内的前 10 条消息自动观察，命中 ≥2 个广告特征（链接/加微信/兼职刷单/优惠券等 20+ 关键词）即告警管理员附**证据+一条 `#踢` 指令**（每人群只告一次，`manage.order.ads_watch: false` 可关）；只告警不动人
- **群活跃周报**（v1.7.2）：`app.weekly_report` 开启后每周一（weekday 可配）上午自动汇总各群近 7 天**发言量/活跃人数/本周沉淀问答数/待解决数 + AI 热点摘要**，合成一条周报推送；LLM 挂了降级高频词简版
- **#踢 二次确认**（v1.7.2）：管理员发 `#踢 昵称 [群名]` → 机器人回**证据预览**（TA 近期发言）→ `#确认踢` 才真正执行 UIA 自动移出（右键头像 →「移出群聊」→ 确认弹窗）；任何一步找不到入口立即放弃并提示人工路径，**绝不误伤**；确认令牌 5 分钟过期，dry_run 只演练；失败自动通知管理员改走群设置手动移出
- **导航吸顶 + 欢迎语占位符容错**（v1.7.3）：网页控制台**标题栏+快捷导航药丸整体吸顶**，往下翻页随时能点导航跳转；进群欢迎语占位符 `{name}`/`$name$`/`$names$`/`%name%`/`{昵称}` 一律识别替换（此前配置里写 `$names$` 会原样发出去），文本里其它花括号也不再导致欢迎语发送失败
- **吐槽收集 + 每日复盘**（v1.7.4）：自动收集群里/私聊/对话台里**对机器人的吐槽**（吐槽词命中 + 提到机器人/引用机器人消息双条件，防误捞吐槽别人的），每晚 21:45 LLM 归纳 **2~4 类共性问题 + 每类一条可落地优化建议**推给主人（`app.complaint_review`，只发一条不打扰群友）；LLM 挂了降级高频词简版；`#吐槽` 随时看吐槽原声
- **群内定时回顾**（v1.7.5）：群配置 `digest.to_group` 勾上后，该群每天在日报时刻把**近 24 小时回顾总结（AI 热点摘要 + 未解问题）直接发进群聊**——群友"@机器人 每天晚上9点回顾总结群里发生的事情"这类诉求一键满足（网页群卡片「回顾发进群」开关）；照旧过闸门，其余群不受影响仍只发主人
- **非管理员任务请求指路**（v1.7.6）：群友说"每天晚上9点回顾总结群里的事"这类定时任务式请求，此前会硬走知识库答疑、经常答非所问；现在识别"定时词+任务动词"（每天/定时/固定 × 总结/提醒/播报…）后礼貌指路"得群主或管理员发话，让TA @我 说一声就能安排上"；管理员的请求照旧直达建任务链路；"每天锻炼好吗"这类含"每天"的普通问题不受影响
- **响应大提速：会话级并行处理**（v1.7.7）：主循环此前是单线程串行——任何一个群的慢链路（KB 沉淀提炼+逐条入库十几秒、免@判定、LLM 生成）都会拖住**所有群**的消息拾取，群多时 @机器人 常要等 1 分钟才被理；现在每个会话（群/私聊/对话台）一个专属 worker 线程保序处理，群间互不阻塞，消息拾取 ≤1 秒（轮询默认 1.5→1.0 秒）；配套三刀：**KB 沉淀转后台线程**（不再占应答路径，同群防重入）、**私聊连发合并智能等待**（对方消息已静默就立即处理，不再傻等 5 秒）、**KB 应答检索 8 秒快速失败**（`kb.ask_timeout`，超时走 LLM 兜底，不再干等 60 秒）；UIA 发送加进程级锁，多群并发回复绝不互踩微信窗口
- **连问只答最新 + 不再答错人**（v1.7.8）：答疑计算要几十秒，期间提问人又追发一条新 @（"刚才那问错了，其实是…"）时，机器人此前仍按旧问题作答；现在答题前会**预看一眼该用户是否追发了新 @**，有就改答最新那条（旧问题自动记入补报缓存，答完在日报里可见）；不同群友的 @ 互不顶替，答过的消息绝不重复作答；配套**引用回复不错人**——所有 @ 消息都以"@机器人"开头，此前正文定位的兜底探针会退化成命中**任何人**的 @ 消息（常引到刚插话的人头上），现在先剥掉 @ 前缀再匹配正文，并优先命中**紧挨提问人昵称标签**的那一行；**"每日统计"等任务词识别扩展**：此前群里说"每日统计一下活跃情况"会被当普通问题硬答知识库，现在与"每天/定时/总结/提醒"同属任务词族——管理员说就建定时任务并答复确认时间，非管理员明说没权限并指路找群主/管理员
- **对话台答问以最新消息为准**（v1.7.9）：在文件传输助手问助手时，此前检索出的**旧记录**（关键词命中多的优先）会淹没你刚说的话——你明明在纠正"是明天停水"，它还翻前天的记录硬顶；现在检索记录按**时间新到旧**喂给模型、**对话台最近几轮往来一并注入上下文**，prompt 明说"你当前这条问题最高优先，旧记录与最新说法冲突时以你为准"，不再翻旧账

## 配置要点（bot_config.yaml）

- `llm`：人设对话生成（provider/base_url/api_key/model/temperature/timeout 均可配）
- `kb`：群答疑知识库（MCP 网关，需自行部署或填写可用网关；未配置时私聊功能不受影响）
- `ocr`：图片识别服务（可选，paddle OCR MCP：url/api_key/timeout；不配则图片只显示 `[图片]`）
- `asr`：语音识别服务（可选，OpenAI 兼容 `/v1/audio/transcriptions`：url/api_key/model/timeout；不配则语音只显示 `[语音]`）
- `contacts`：`id`（微信号/wxid，不知道可只填 `display` 自动反查；更推荐直接从 Web 页"最近会话"点选）+ `persona` + `enabled`
- `groups`：`--list` 查 id 或 Web 页点选；`admins` 按群添加指令管理员（填昵称即可）；`max_reply_chars` 回复字数上限（0=不限）；`qa.stale_min` @过气时限（分钟，默认 10）；`qa.enabled` 答疑开关；`no_at_reply` 免@接话（`no_at_context`/`no_at_cooldown_min` 可调，Web 页群卡片有开关）；`manage` 段配欢迎/违禁词/`warn_persona`/`warn_threshold`；`mention_names` 可加额外 @称呼（默认自动含自己的微信昵称）
- `app.dry_run: true` 只记日志不发送（**模板默认开**，新装机先在演示模式验证）
- `app.daily_digest`：每晚群精华日报（enabled/hour/push_to；群还要勾 `digest.enabled` 才出小节；`digest.to_group` 让该群回顾直接发进群聊）
- `app.weekly_report`：群活跃周报（enabled/weekday/hour/push_to；默认周一 9 点，开启后所有启用群都进周报）
- `app.complaint_review`：吐槽复盘（enabled/hour/push_to；每晚自动 LLM 归纳对机器人的吐槽共性+优化建议，`#吐槽` 随时看原声）
- `manage.order.ads_watch`：新成员广告嫌疑观察（默认开；告警附 #踢 指令，踢人需人工 #确认踢）
- `app.missed_private`：非白名单私聊被动监控入补报（默认开；急件即时推；绝不自动回复）
- `app.gate`：主动动作闸门（hourly_max/per_chat_daily_max/window 时段窗；`#急停主动` 急停）
- `app.update_mirror`：升级检查国内镜像源（自建 nginx 静态目录的 URL，如 `http://your-server:21120/wxbot-update`）；留空走 GitHub，配了优先镜像、失败自动回落
- `app.self_wxid` / `app.setup_done`：程序自动维护（多账号隔离标识/向导完成标志），勿手改

## 数据与升级

- **升级不丢数据**：安装/升级只替换程序目录（`%LocalAppData%\Programs\Wxbot`），配置、数据库（画像/记忆/问答沉淀/日志）都在 `%APPDATA%\wxbot\<wxid>\`，卸载重装、覆盖升级均原样保留
- **换号迁移**：换微信号登录后新账号目录是空的，用 Web 页「群友画像 → 跨账号迁移」先在旧账号导出 JSON、再到新账号导入即可
- **喂更多历史**：PC 本地库只有 PC 端同步/收到的消息；想把手机上的完整历史变成画像，先在手机微信里把聊天记录迁移到电脑（与 PC 微信同账号、同一局域网操作最稳），迁移完成后在目标群点「🚀 全量冷启动」并调大扫描条数

## 安全与风控

- 发送前**硬校验**目标会话（会话名不符绝不输入），粘贴后内容比对不符不回车，open_chat 偶发失败自动重试 3 次
- 回复带拟人迟延（2~5s 随机）、连发合并安静窗口（5s）、发送串行
- 锁屏会拦截一切模拟输入（读消息不受影响）——常开请禁自动锁屏
- 微信窗口须保持存在；建议小号专用，注意频控
- 聊天记录中的卡号/开户/证件号等会脱敏后再送 LLM

## 已知限制

- 踢人未做全自动（4.x 群设置 UI 自动化误踢风险高），走"人设劝告 + 阈值告警 + 人工移出"
- @提醒通知依赖文本匹配（群昵称与微信昵称不一致时需在 `mention_names` 补充）
- 群内 @某人 仅文本显示，不含微信官方 @ 通知效果
- 语音识别需自备 ASR 服务（OpenAI 兼容接口直收 SILK；服务端需支持 SILK 或自行转码），不配置时上下文显示 `[语音]`；图片 OCR 需自备 paddle OCR MCP 服务，图片为"已收到并在本地有缓存"时才可解密（很老的图/未点开过的可能拿不到）；原生引用回复依赖 UIA 右键菜单，微信改版菜单文案时自动降级为文本前缀回复
- `kb` 写入走网关的 `kb_add_qa`（问答对，同库同问自动去重）：免@增量消息自动提炼成问答对入库，"群历史挖掘问答库"卡片有「同步问答入库」一键把本地挖掘的问答批量写入；入库失败本地水位不前移、待下次重试。网关若另有整篇文档上传工具（`kb_upload` 等）也可用 `kb.upload_tool` 指定（v1.4.5 前的旧链路，现默认走 kb_add_qa）

## 构建 MSI（Windows）

```
pip install pyinstaller && pip install -e vendor/wechatauto-replica
pyinstaller wxbot.spec --noconfirm
cd build && python gen_files.py ..\dist\wxbot
wix build -arch x64 product.wxs files.wxs -o wxbot.msi
```

需要 [WiX v6](https://wixtoolset.org/)（`dotnet tool install --global wix`）与 .NET 8 SDK。

**CI**：GitHub Actions 会在每次 push 时自动跑测试并构建 MSI（Actions 页下载产物）；打 `v*` 标签自动发布 Release。
